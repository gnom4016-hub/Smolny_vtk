# СМОЛЬНЫЙ — сайт

Статический сайт: только HTML, CSS и JS. Никакой сборки, серверов и зависимостей.

## Структура

```
smolny/
├── index.html              главная страница
├── css/style.css           все стили, тёмная и светлая тема
├── js/products.js          ← ТОВАРЫ, ЦЕНЫ, НИК В TELEGRAM
├── js/app.js               логика: каталог, карточка, корзина
└── assets/
    ├── logo-gold.png       полный логотип для тёмной темы
    ├── logo-dark.png       полный логотип для светлой темы
    ├── crest-gold.png      только герб (шапка, favicon)
    ├── crest-dark.png      герб для светлой темы
    ├── word-gold.png       надпись «СМОЛЬНЫЙ» + подпись
    ├── word-dark.png
    ├── favicon.png
    └── products/           ← СЮДА КЛАДЁТЕ ФОТО ОДЕЖДЫ
```

Логотипы вырезаны из вашего PDF в оригинальном виде, с прозрачным фоном,
шириной около 1245 px — хватит для экранов Retina.

## Первое, что нужно сделать

Откройте `js/products.js` и в самом верху замените ник:

```js
var SHOP = {
  telegram: 'smolny_store',   // ваш ник без собачки
  currency: '₽'
};
```

## Как добавить фото товара

1. Положите снимки в `assets/products/`. Вертикальные, пропорции 3:4,
   ширина от 1200 px, формат `.jpg` или `.webp`.
2. Впишите пути в товар:

```js
photos: [
  'assets/products/shinel-1.jpg',
  'assets/products/shinel-2.jpg',
  'assets/products/shinel-3.jpg'
],
```

Если фото нет или путь с опечаткой — вместо снимка покажется фактурная
заглушка в цветах вещи. Сайт не сломается.

## Как добавить товар

Скопируйте любой блок в массиве `PRODUCTS` и поменяйте поля.
`id` должен быть уникальным и латиницей — он попадает в адрес страницы.
Новая категория в `cat` сама появится в фильтрах.

`sizes: [{ s: '48', in: 1 }]` — `in: 1` есть в наличии, `in: 0` распродан
(размер будет перечёркнут и некликабелен).

## Как работает заказ

Оплаты на сайте нет. По кнопке «Оформить в Telegram» сайт собирает текст
заказа, копирует его в буфер и показывает окно с кнопкой перехода в ваш чат.
Покупатель вставляет сообщение — дальше вы общаетесь напрямую.

Содержимое корзины сохраняется в браузере: закрыл вкладку, вернулся — всё на месте.

## Как открыть локально

Просто дважды кликните `index.html`. Для корректной работы шрифтов
лучше поднять локальный сервер:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Как выложить в интернет

Подойдёт любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages,
или обычный хостинг по FTP. Загружаете папку целиком — сайт работает.
Для своего домена достаточно направить A-запись на хостинг.

## Адаптивность

Проверено на ширинах 320, 375, 414, 768, 1024, 1440 и 1920 px, а также в
альбомной ориентации телефона. Учтены вырезы экранов iPhone (safe-area),
сетка каталога перестраивается 3 → 2 → 1 колонку, на телефоне кнопка
«В корзину» закреплена внизу экрана карточки товара.

## Мелочи, которые уже сделаны

- Тема запоминается между визитами.
- Адрес карточки товара вида `#/product/shinel` — ссылкой можно поделиться.
- Работает кнопка «назад» в браузере и клавиша Esc.
- Учтена системная настройка «уменьшить движение».
- Фокус с клавиатуры виден, у кнопок есть доступные подписи.
